## Sobre o Blog

Este é o repositório do meu blog pessoal, onde compartilho reflexões sobre:

- **Neurodiversidade** (autismo, TDAH, etc.)
- **Rotina e vida adulta**
- **Aprendizados em programação**
- **Dicas de organização e autocuidado**

O blog começou apenas como um projeto de diário pessoal, mas também virou um recurso para aprender HTML e CSS, e outras linguagens

---

## Tecnologias usadas
- HTML5 - Estrutura das páginas
- CSS3 - Estilização visual
- Markdown - Escrita dos posts 
- Git/GitHub - Versionamento
